# Maintainer documents

Documents for the people who maintain Polhem. They are written in English only; the documentation for developers who
build applications with Polhem is under [`docs/`](../docs/README.md). The reasons for the split are in
[ADR-047](adr/adr-047-documents-split-by-reader.md).

| Document | Content |
|----------|---------|
| [adr/](adr/README.md) | Architecture decision records: the context and the reasons at the time a decision was made |
| [gotchas/](gotchas/README.md) | Pitfalls that have been hit and are likely to be hit again, with the symptom, the root cause and the fix |
| [branch-protection-setup.md](branch-protection-setup.md) | Branch protection and repository settings |
| [ci-sonarcloud-setup.md](ci-sonarcloud-setup.md) | SonarCloud setup |
| [public-api-baseline.md](public-api-baseline.md) | Maintaining the public API baseline (`PublicAPI.*.txt`) |
| [testing-patterns.md](testing-patterns.md) | Copy-ready test templates |
| [load-testing.md](load-testing.md) | How load tests are measured and read |
| [future-work.md](future-work.md) | Ideas that are not scheduled yet |
| [pagination-prior-art.md](pagination-prior-art.md) | External evidence on pagination |
| [uom-decimals-prior-art.md](uom-decimals-prior-art.md) | External evidence on unit-of-measure decimals |
