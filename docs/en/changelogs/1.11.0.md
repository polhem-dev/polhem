# Polhem 1.11.0 — Release Notes

[繁體中文](../../zh-TW/changelogs/1.11.0.md)

This file holds the details behind the `[1.11.0]` entry in [CHANGELOG.md](../../../CHANGELOG.md).

This version is in progress. Its wire format is the one of 1.10.0.

## New features and changes

### Template strings in Traditional Chinese

The name, description and options of the `polhem-avalonia` template are translated into Traditional Chinese
(`zh-Hant`). `dotnet new` shows them when its language is Traditional Chinese (`DOTNET_CLI_UI_LANGUAGE=zh-TW` or
`zh-Hant`), and the New Project list of the C# Dev Kit in VS Code shows them when the operating system's language is
Traditional Chinese; zh-TW and zh-HK fall back to zh-Hant. Every other language shows the English. Reload the VS Code
window after installing or updating the template package.

### A ready-made shell for Blazor Server

`Polhem.Web.Blazor.Server` gains `Polhem.Web.Blazor.Server.Shell`, the front end of a site in a few lines, as
`Polhem.UI.Avalonia.Shell` is for the Avalonia heads. `PolhemShellLayout`, the router's default layout, shows a sign-in
screen (company, user, password) until the circuit's user has entered a company, then a top bar with the title, the
user and company and Sign out, the server's menu, and the routed page. On a screen narrower than 600 CSS pixels the menu
slides over the page. The sign-in screen switches between English and Traditional Chinese through a new `GET /culture`
endpoint, which redirects only to a path on the site.

A site registers it with `AddPolhemShell` (title, sign-in hint, default company, user and password, the offered
languages and the default culture, the form route), adds `UsePolhemShellLocalization` and `MapPolhemShellCulture` to its
pipeline, sets `PolhemShellLayout` as the default layout, and keeps a root page with `PolhemShellHome` and a form page
with `FormPage`. The package README shows the whole setup. The Northwind Blazor head now runs on it.

`PolhemLoginPanel` gains `InitialUserId` and `InitialPassword`, which fill its inputs once.

### A default stylesheet for the Blazor components

The package ships `_content/Polhem.Web.Blazor.Server/polhem.css`, the default look of the components and the shell.
It is optional: until now every site styled the `polhem-*` classes itself, and a site that keeps doing so is
unaffected. Its colours are custom properties (`--polhem-accent`, `--polhem-surface` and others), so a site's own sheet,
linked after it, restyles it by redefining them.

## Breaking changes

None.
