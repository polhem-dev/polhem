# Polhem 1.11.0 — Release Notes

[繁體中文](../../zh-TW/changelogs/1.11.0.md)

This file holds the details behind the `[1.11.0]` entry in [CHANGELOG.md](../../../CHANGELOG.md).

This version is in progress. Its wire format is the one of 1.10.0.

## New features and changes

### `AddPolhemBackend`: the backend in one call

`Polhem.Hosting` gains `AddPolhemBackend`, an extension of `IHostApplicationBuilder` (a web application, a Worker
Service, a generic host). It makes the calls every backend host made before `AddPolhemFramework`, in order: it finds the
`Define` folder above the build output, adds the framework's default definitions the folder does not have yet, reads
`SystemSettings.xml`, initializes `SysInfo`, and calls `AddPolhemPayload` and `AddPolhemFramework`. It returns the
`PathOptions` it registered.

```csharp
var builder = WebApplication.CreateBuilder(args);
builder.AddPolhemBackend(options => options.AutoCreateMasterKey = true);
builder.Services.AddJsonRpcServer();
```

`PolhemBackendOptions` names a definition folder (`DefinePath`) and a customization root (`CustomizePath`), turns
adding the defaults off or filters them (`MaterializeDefaults`, `MaterializeOptions`), and lets a development host
create its master key (`AutoCreateMasterKey`). Register the database providers yourself, as before. Existing hosts that
make these calls themselves keep working; the `polhem-avalonia` template's server now uses `AddPolhemBackend`.

### Template strings in Traditional Chinese

The name, description and options of the `polhem-avalonia` template are translated into Traditional Chinese
(`zh-Hant`). `dotnet new` shows them when its language is Traditional Chinese (`DOTNET_CLI_UI_LANGUAGE=zh-TW` or
`zh-Hant`), and the New Project list of the C# Dev Kit in VS Code shows them when the operating system's language is
Traditional Chinese; zh-TW and zh-HK fall back to zh-Hant. Every other language shows the English. Reload the VS Code
window after installing or updating the template package.
