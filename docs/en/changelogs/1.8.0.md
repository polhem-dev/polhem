## New features and changes

### Render a form layout without data

`FormLayoutPresenter` (`Polhem.UI.Avalonia.Controls`) renders the body of a form from a `FormLayout` alone: the master
sections with one field editor per `LayoutField`, laid out by `ColumnCount` and the spans, followed by the detail
grids. It needs no data, schema or backend, so a design tool can show a layout while it is being edited:

```csharp
var preview = new FormLayoutPresenter { Layout = layout };
FormScope.SetFormMode(preview, SingleFormMode.Edit);
```

Without data, the editors follow the layout's `ReadOnly` and `AllowEditModes` under the form mode, and each detail
grid shows the toolbar its `AllowActions` allow, with the buttons disabled. Drop-down items, field values, lookup text
and computed fields come from the schema or the data and are not shown. Changing a property renders again; after
changing the layout in place, call `Refresh()`. `IsCompact` renders the phone-sized form.

`FormView` now renders its record through this control, so the two draw a layout the same way. What `FormView` shows
does not change.

### Live FormLayout preview in DefineEditor

The FormLayout editor shows a preview under the property grid, drawn by `FormLayoutPresenter`. It redraws shortly after
each edit: a property written in the grid, a section, field, grid or column added, deleted or reordered. It can show
View mode or the phone-sized form, and puts each field's name into empty fields. Unchecking **Show** collapses it to
its header.
