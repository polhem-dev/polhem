# Polhem 1.8.0 — 發佈說明

[English](../../en/changelogs/1.8.0.md)

本檔是 [CHANGELOG.zh-TW.md](../../../CHANGELOG.zh-TW.md) 中 `[Unreleased]` 條目的詳細內容，發佈時改為 `[1.8.0]`。

本版尚未發佈。wire 格式與 1.7.0 相同。

## 新功能與變更

### 不帶資料渲染表單版面

`FormLayoutPresenter`（`Polhem.UI.Avalonia.Controls`）只依 `FormLayout` 渲染表單本體：主檔 sections，每個
`LayoutField` 一個 field editor，依 `ColumnCount` 與跨欄跨列排列，其後是明細。它不需要資料、schema 或後端，
因此設計工具可以在編輯 layout 的同時顯示它：

```csharp
var preview = new FormLayoutPresenter { Layout = layout };
FormScope.SetFormMode(preview, SingleFormMode.Edit);
```

沒有資料時，欄位編輯器依表單模式套用 layout 的 `ReadOnly` 與 `AllowEditModes`，每個明細依 `AllowActions`
顯示工具列，但按鈕停用。下拉選項、欄位值、lookup 顯示文字與計算欄位來自 schema 或資料，不會顯示。
修改屬性會重新渲染；就地修改 layout 之後，呼叫 `Refresh()`。`IsCompact` 會畫出手機尺寸的版面。

`FormView` 現在透過這個控件渲染記錄，因此兩者畫 layout 的方式一致。`FormView` 顯示的內容不變。

### DefineEditor 的 FormLayout 即時預覽

FormLayout 編輯器在屬性方格下方顯示預覽，由 `FormLayoutPresenter` 繪製。每次編輯後稍待片刻就會重畫：
在方格中寫入屬性，或新增、刪除、重新排序 section、欄位、明細或明細欄位。可以切換為檢視模式或手機尺寸的版面，
並在空白欄位顯示欄位名稱。取消勾選**顯示**會把預覽收合成只剩標題列。

### DefineEditor 配色

DefineEditor 改用 VS Code **Dark (Visual Studio)** 與 **Light (Visual Studio)** 主題的配色：背景、輸入欄位、主色、
選取與焦點色，以及較淡的分隔線。每條窗格分隔線在滑鼠移上或拖曳時改為焦點色，與 VS Code 的 sash 相同。

### DefineEditor 側欄檢視

左側新增 VS Code 式的 Activity Bar，側欄可從三個角度檢視同一批定義檔：

- **檔案總管**：DefinePath 資料夾的檔案，與先前相同。
- **功能**：`ProgramSettings.xml` 登記的每個 ProgId，底下列出它的 FormSchema、FormLayout、各資料表的 TableSchema
  與 Language 檔。
- **資料庫**：`DbCategorySettings.xml` 的每個類別與其資料表；點資料表開啟對應的 TableSchema。

再點一次目前檢視的圖示會收合側欄，選擇的檢視在下次啟動時還原。

### DefineEditor TableSchema 編輯器的 CREATE TABLE

TableSchema 編輯器的屬性方格下方新增 **CREATE TABLE** 面板，顯示正在編輯的資料表的建表語法。在標題列選 SQL Server、
PostgreSQL、MySQL、Oracle 或 SQLite；語法隨編輯即時更新，**複製**會放到剪貼簿。語法來自 `Polhem.Db` 中執行期建表用的
同一組方言產生器，所以包含各資料庫的索引與描述語法。取消勾選**顯示**會把面板收合成只剩標題列。

### 用 Excel 活頁簿描述表單

表單可以在 Excel 活頁簿中描述，再匯入成定義檔，讓熟悉表單的人在開發人員動手寫 XML 之前就能先建模。一份活頁簿描述
一張表單：資料表、欄位、驗證規則與選單位置；只能填固定值的欄位有下拉選單，每個顯示文字旁邊都有中文欄。

```bash
dotnet polhem forms template --out Quote.xlsx
dotnet polhem forms import Quote.xlsx --define ./Define --dry-run
dotnet polhem forms export Quote --define ./Define --out Quote.xlsx
```

匯入會補上框架慣例決定的部分（系統欄位、關聯的 `ref_*` 欄位、`ft_` 表名、`company` 範圍），驗證表單，再寫入
FormSchema、每張表一份的 TableSchema、尚無版面時的 FormLayout、`DbCategorySettings.xml`、`ProgramSettings.xml`、
`MenuSettings.xml` 中的登記，以及中文語系檔。有錯誤時不寫入任何檔案。DefineEditor 的 **File** 選單提供相同的匯入，
FormSchema 節點則可匯出。見 [用 Excel 建模表單](../guides/excel-form-modeling.md)。

### 修正

- **產生的明細表 TableSchema 會替主檔欄位建立索引。** `TableSchemaGenerator`（以及 Excel 匯入用來寫出 TableSchema 檔的
  `FormTable.GenerateDbTable`）現在會替每張含 `sys_master_rowid` 欄位的資料表加上名為 `fk_{0}_master` 的非唯一索引。
  載入或刪除某筆資料的明細時都以此欄位過濾，沒有索引時每次讀取都要掃描整張明細表。範例與 Northwind 中手寫的明細表 TableSchema
  原本就以相同名稱宣告了這個索引。

  對既有資料庫的影響：已存在的 TableSchema 檔不會改變。若重新產生或重新匯入某張明細表的 TableSchema，下一次 schema
  升級會在該表建立 `fk_{0}_master`。在大型資料表上建立索引需要時間，且依資料庫不同可能會阻擋對該表的寫入，請比照其他
  新增索引的升級安排時機。已宣告 `fk_{0}_master` 的 TableSchema 不會多出第二個索引。
