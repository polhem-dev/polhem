# Polhem 1.11.0 — 發佈說明

[English](../../en/changelogs/1.11.0.md)

本檔是 [CHANGELOG.zh-TW.md](../../../CHANGELOG.zh-TW.md) 中 `[1.11.0]` 條目的詳細內容。

本版尚在開發中。wire 格式與 1.10.0 相同。

## 新功能與變更

### 範本字串的繁體中文翻譯

`polhem-avalonia` 範本的名稱、說明與選項翻譯成繁體中文（`zh-Hant`）。`dotnet new` 的語言是繁體中文時
（`DOTNET_CLI_UI_LANGUAGE=zh-TW` 或 `zh-Hant`）會顯示中文；VS Code 中 C# Dev Kit 的 New Project 清單在作業系統語言是繁體中文時顯示中文，
zh-TW 與 zh-HK 都會退回使用 zh-Hant。其他語言顯示英文。安裝或更新範本套件後，請重新載入 VS Code 視窗。

## 破壞性變更

無。
