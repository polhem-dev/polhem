# Polhem 1.1.0 — 詳細發佈說明

[English](../../en/changelogs/1.1.0.md)

本檔是 [CHANGELOG.zh-TW.md](../../../CHANGELOG.zh-TW.md) 中 `[1.1.0]` 條目的詳細版。變更記錄每項變更只列一行；原因與背景
留在這裡。

> `Polhem.Base` 改名為 `Polhem.Core`。依語意化版本，這應等到 2.0.0；它以一次性例外在 1.1.0 發佈。決策與替代方案記錄在
> [ADR-048](../../../maintainers/adr/adr-048-rename-base-to-core-in-1-1.md)（英文）。

## 為什麼在 minor 版做破壞性變更

框架最底層的組件原本就打算叫 `Polhem.Core`。Polhem 1.0.0 於 2026-09-28 發佈時，沿用了從 Bee.NET 繼承來的名稱，而改名
的代價只會隨使用舊名稱的應用程式數量增加。1.0.0 發佈兩天時，就所知這個數量是零。

1.0.0 發佈兩天就出主版本，只為了一個還沒人採用的改名，會傳達一場並未發生的大變動。因此改名在 1.1.0 發佈，並下架
（unlist）所有 `Polhem.*` 的 1.0.0 套件：鎖定 1.0.0 的應用程式仍可 restore，但新的應用程式不會從舊名稱開始。用 minor
而不用 patch，是因為自動相依更新最放心套用的是 patch 版，藏在 patch 裡的破壞最容易沒人注意。

這是唯一的例外。從 1.1.0 起，1.x 依 [ADR-046](../../../maintainers/adr/adr-046-api-evolution-policies-for-1-0.md)（英文）
所述的語意化版本演進。

## 破壞性 API 變更

- `Polhem.Base` 改名為 `Polhem.Core`：套件 ID、組件與所有命名空間（`Polhem.Base.Serialization` →
  `Polhem.Core.Serialization`、`Polhem.Base.Collections` → `Polhem.Core.Collections`，依此類推）。型別名稱不變。沒有
  相容 shim：`TypeForwardedTo` 能把型別轉送到另一個組件，但無法改變它的命名空間。
  ([#42](https://github.com/polhem-dev/polhem/pull/42))

從 1.0.0 升級：

1. 專案若直接參考 `Polhem.Base`，換成 `Polhem.Core`。多數應用程式不需要：其他每個 Polhem 套件都會帶入它。
2. 把 `using` 指示詞與完整限定型別名稱中的 `Polhem.Base` 換成 `Polhem.Core`。
3. 建置。剩下沒改到的地方編譯器會逐一回報。
4. 若有設定 `AllowedTypeNamespaces`，檢查它（見下一節）。

```diff
- <PackageReference Include="Polhem.Base" Version="1.0.0" />
+ <PackageReference Include="Polhem.Core" Version="1.1.0" />
- using Polhem.Base.Serialization;
+ using Polhem.Core.Serialization;
```

## 行為變更

- 內建的 JSON-RPC 型別命名空間白名單列的是 `Polhem.Core`，不再是 `Polhem.Base`，所以 `Polhem.Base` 開頭的型別名稱會像
  其他未知命名空間一樣被拒絕。內建清單原本在 `SysInfo` 寫了兩次，現在只寫一次。自訂的 `AllowedTypeNamespaces` 若列了
  `Polhem.Base`，將不再比對到任何型別，可以移除；內建命名空間本來就不需要列出。wire fixtures 不受改名影響。
  ([#42](https://github.com/polhem-dev/polhem/pull/42))

## 範例與工具

- 移除 `Web.Js.Demo` 範例（原生 JavaScript 用戶端）。JavaScript 用戶端統一使用
  [polhem-connector-js](https://github.com/polhem-dev/polhem-connector-js)，[前端整合指南](../api/jsonrpc-frontend-integration.md)
  與各 README 都指向它。`QuickStart.Server` 保留給瀏覽器用戶端的 CORS 政策。
  ([#41](https://github.com/polhem-dev/polhem/pull/41))
