# Polhem 1.9.0 — 發佈說明

[English](../../en/changelogs/1.9.0.md)

本檔是 [CHANGELOG.zh-TW.md](../../../CHANGELOG.zh-TW.md) 中 `[1.9.0]` 條目的詳細內容。

本版讓定義的修改可以在 DefineEditor 裡一路完成，不必回到 Excel；現成前端改為適合手機的操作方式；應用程式也可以決定啟動時的主題。
另外修正了 UI 自動化與 VoiceOver 在殼與 DefineEditor 樹狀清單上做不到的操作。wire 格式與 1.8.0 相同，1.8.0 的用戶端與
1.9.0 的伺服器（或反過來）可以互通。

## 新功能與變更

### 在 DefineEditor 把 FormSchema 同步到它的 TableSchema 與 FormLayout

在 FormSchema 新增欄位後，執行 schema 節點上的 **同步 TableSchema 與 FormLayout**（FormSchema 為作用中分頁時，**File** 選單也有），
就能讓表單的其他定義檔跟上。它以合併模式規劃一次已存檔表單的匯入，所以只會新增：新欄位會放進 TableSchema 與 FormLayout，
位置在表單上相鄰欄位的旁邊；新的明細表會被登記；被移除的欄位或改了型別的欄位只會列為警告，不會套用。主檔新增的可見欄位也會加到表單的
`ListFields`；空白的 `ListFields` 代表列出所有欄位，維持空白。

旁邊的 **升級此表單的資料表** 只升級該表單的資料表，執行前可先預覽語法。

版面的部分也提供給程式使用：`FormLayoutGenerator.Merge(layout, schema)`（`Polhem.Definition.Layouts`）會補上 schema 有、
版面沒有的欄位與明細表格，不修改也不移除任何東西，並回傳補上的名稱。表單活頁簿匯入也能以同樣方式補進既有版面，
重新匯入活頁簿時，不必再在「保留手動調整過的版面」與「重新產生」之間二選一。

### 選擇 FormLayout 編輯器右側要顯示什麼

FormLayout 編輯器上方的按鈕可切換右側顯示屬性格加預覽（預設）、只顯示預覽，或只顯示屬性格。不顯示屬性格時，可從工具列或節點右鍵選單的
**屬性設定…** 開啟對話框，用同樣的屬性格編輯所選節點；在對話框中的修改會標示文件已變更並更新樹狀清單，⌘S 可存檔。

### 收合 DefineEditor 的側欄

**View › Toggle Side Bar**（⌘B；非 macOS 為 Ctrl+B）可收合側欄，讓 FormLayout 預覽等編輯器佔滿整個視窗，與 VS Code 相同。

### 手機一次只顯示一個表單

在 iOS 與 Android 端，`Polhem.UI.Avalonia.Shell` 改為以一個佔滿畫面的表單取代文件分頁：選另一個選單項目就取代目前的表單；
選單從表單上方滑出，一開始是收起的，選好項目後自動收起。返回鍵會先把開啟中的記錄退回清單，再離開 App。桌面與瀏覽器端維持分頁。

### 選擇殼啟動時的主題

`ShellOptions.DefaultThemeVariant` 設定殼啟動時的主題。應用程式沒有設定時為淺色，表單畫面上的深淺切換會從目前實際的主題開始：

```csharp
protected override ShellOptions CreateOptions() => new()
{
    AppTitle = "MyApp",
    DefaultThemeVariant = ThemeVariant.Dark,
};
```

從本版起以 `polhem-avalonia` 範本建立的專案預設為深色，Northwind 範例也是；想從淺色開始，刪掉產生的 `App.cs` 中這一行即可。
先前建立的專案不受影響。

### 修正

- **瀏覽器端殼的選單鈕與分頁關閉鈕。** 原本顯示 U+2630 與 U+2715 兩個字元，內嵌的 Inter 字型沒有這兩個字形。桌面端會借用系統字型，
  瀏覽器端沒有可借用的字型，因此畫成替代符號。兩個按鈕現在都改畫向量圖示。
- **透過無障礙介面的選取。** 以 macOS 無障礙介面（VoiceOver 與 UI 自動化的做法）選取殼的選單項目時，只會反白而不會開啟表單，
  現在會開啟。以同樣方式選取單選樹狀清單的一列時，原本選取的那一列仍是選取項目，綁定選取的編輯器因此不會跟著切換。新的
  `TreeViewExtensions.KeepSelectionSingle`（`Polhem.UI.Avalonia.Controls`）會讓新加入的那一列成為選取項目；`ObjectTreeView` 與
  DefineEditor 的側欄樹狀清單都已套用。`DataGrid` 的列與儲存格仍無法以這種方式選取，因為 DataGrid 的 automation peer 不支援
  （[#149](https://github.com/polhem-dev/polhem/issues/149)）。
