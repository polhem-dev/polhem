# Polhem 1.13.0 — 發佈說明

[English](../../en/changelogs/1.13.0.md)

本檔是 [CHANGELOG.zh-TW.md](../../../CHANGELOG.zh-TW.md) 中 `[Unreleased]` 條目的詳細內容，發佈時會成為 `[1.13.0]`。

本版尚未發佈。Avalonia 與 Blazor head 現在共用同一個位於 `Polhem.UI.Core` 的 `FormDataObject`。

## 新功能與變更

無。

## 破壞性變更

### `FormDataObject` 移至 `Polhem.UI.Core`

- **影響對象：** 在 Avalonia head 或 Blazor head 中指名 `FormDataObject`、`FieldValueChangedEventArgs` 或
  `RowChangedEventArgs` 的程式，以及自行建構 `FormDataObject` 的程式。
- **原本：** 兩個 head 各有一份：`Polhem.UI.Avalonia.DataObjects.FormDataObject` 接受 `IFormApiConnector`，
  `Polhem.Web.Blazor.DataObjects.FormDataObject` 接受 API client 的 `FormApiConnector`。新資料列日期所用的時區，
  Avalonia 那份取自 `UIServices.Provider` 中的 `IUserContext`，Blazor 那份取自其連接器的 client。
- **現在：** 只有一個型別 `Polhem.UI.Core.DataObjects.FormDataObject`，接受 `IFormApiConnector`，並可選擇傳入一個回傳
  登入使用者 IANA 時區 id 的函式。未傳入時，新資料列的日期預設為 UTC 的今天。`FormView`、`FormPage` 與關聯紀錄對話框
  都會傳入使用者時區，透過它們開啟的表單行為不變。`FormLiveComputation` 仍留在各 head。
- **遷移：**
  1. 替換命名空間：

     | 原本 | 現在 |
     |------|------|
     | `Polhem.UI.Avalonia.DataObjects.FormDataObject` | `Polhem.UI.Core.DataObjects.FormDataObject` |
     | `Polhem.Web.Blazor.DataObjects.FormDataObject` | `Polhem.UI.Core.DataObjects.FormDataObject` |
     | `Polhem.UI.Avalonia.DataObjects.FieldValueChangedEventArgs` | `Polhem.UI.Core.DataObjects.FieldValueChangedEventArgs` |
     | `Polhem.Web.Blazor.DataObjects.FieldValueChangedEventArgs` | `Polhem.UI.Core.DataObjects.FieldValueChangedEventArgs` |
     | `Polhem.UI.Avalonia.DataObjects.RowChangedEventArgs` | `Polhem.UI.Core.DataObjects.RowChangedEventArgs` |
     | `Polhem.Web.Blazor.DataObjects.RowChangedEventArgs` | `Polhem.UI.Core.DataObjects.RowChangedEventArgs` |

     同時使用 `FormLiveComputation` 的程式，也要保留該 head 的 `DataObjects` 命名空間。
  2. 自行以連接器建構 `FormDataObject`、且新資料列應依使用者的日期預設時，傳入時區。在 Avalonia head：

     ```csharp
     var dataObject = new FormDataObject(schema, connector,
         () => UIServices.Get<IUserContext>()?.User?.TimeZone ?? string.Empty);
     ```

     在 Blazor 元件中，傳入 circuit 自己的時區，不可用整個 process 共用的：

     ```csharp
     var dataObject = new FormDataObject(schema, Client.Form(progId),
         () => Client.Session.Credentials.UserTimeZoneId);
     ```
- **背景：** [ADR-054](../../../maintainers/adr/adr-054-front-end-decoupled-from-api-client.md) 的「Implementation evolution」。
